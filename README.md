# Giọt Nước

Ứng dụng PWA theo dõi thói quen uống nước. Có thể cài lên màn hình chính của iPhone hoặc Android sau khi được xuất bản qua HTTPS.

## Xuất bản bằng GitHub Pages

1. Tạo một kho mã nguồn GitHub mới và tải toàn bộ thư mục này lên nhánh `main`.
2. Trong phần **Settings → Pages** của kho mã nguồn, chọn **GitHub Actions** làm nguồn xuất bản.
3. Sau khi quy trình "Publish Giot Nuoc" hoàn tất, mở đường dẫn Pages trên điện thoại.
4. Android: chọn **Cài ứng dụng** khi trình duyệt gợi ý. iPhone: mở bằng Safari, chạm **Chia sẻ → Thêm vào Màn hình chính**.

Mọi dữ liệu uống nước được lưu cục bộ trên từng thiết bị.
